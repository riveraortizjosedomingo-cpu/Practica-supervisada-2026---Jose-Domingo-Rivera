## Puntos de cambio
1. 360 px = Es excelente para que se adapte a moviles. Usando una columna ya que en estos dispositivos el espacio horizontal es muy reducido.
2. 768 px = Este es excelente para dispositivos un poco mas amplios , como tablets. Para mostrar dos columnas.
3. 1440 px = Este lo use por que es el estandar actual de las pantallas. Algo mas que recomendable para ver con calidad sin perder calidad.
