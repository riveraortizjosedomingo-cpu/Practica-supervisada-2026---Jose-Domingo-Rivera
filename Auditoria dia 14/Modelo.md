# **Plan de respuesta a un incidente**
### Lo mas importante si ocurre un incidente es tener plan para reaccionar de la manera mas eficiente.
1. Identificar = ¿cual fue el problema?
2. Analizamos = ¿Como va a funcionar?
3. En base al problema = ¿Cual sera la solución mas adecuada?
4. Aqui buscamos actuar para resolver el problema
5. Añadimos seguridad para que no vuelva a suceder.
6. Comprobamos que funcione correctamente.
